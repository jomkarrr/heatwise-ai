# HeatWise AI

HeatWise AI is a geospatial AI/ML framework developed for ISRO BAH 2026 to identify urban heat hotspots, analyze the drivers of urban heating, and recommend optimized cooling interventions.

## Features
- Landsat 8 data ingestion
- Sentinel-2 data ingestion
- ERA5 meteorological data ingestion
- OpenStreetMap roads and buildings extraction
- Automated geospatial data pipeline
- Unit-tested architecture

## Project Structure

- `pipelines/` – data ingestion workflows
- `tests/` – unit tests
- `docs/` – project documentation
- `data/external/` – boundary files
